# Roadmap

## Phase structure

Each phase has a goal, boundaries, dependencies, measurable completion criteria, and ordered WPs.

| Phase | Goal | Status |
|---|---|---|
| 1 | Replace with first project outcome | Planned |

## Queue rules

- Execute approved WPs and RWPs only.
- Sequential work follows queue order.
- RWP insertion requires planning approval.
- Future phases may be explicitly paused.
- Phase closure runs the full non-integration regression policy.
